# Estately — Real Estate Listing Platform

Full-stack real estate listing platform built with React (Vite), Express, MongoDB Atlas, and Google Gemini AI.

## What's inside

- **Buyer role** — browse/search/filter properties, save favorites, send inquiries to agents
- **Agent role** — add/edit/delete listings, AI-generated property descriptions (Gemini), view inquiries, track views
- **Admin role** — approve/reject listings, manage users, platform-wide stats
- **AI Chat Assistant** — floating widget where buyers can describe what they want in plain English and get matching suggestions
- Gold/amber luxury theme, 3D tilt hover cards, animated hero background
